# 💌 Invite — دعوت عاشقانه

نسخهٔ اول یک سایت سبک، فارسی، راست‌چین و مناسب گوشی است؛ با HTML، CSS و JavaScript خالص و بدون نیاز به Build یا Docker.

## امکانات نسخه ۱
- «با من میای سر قرار؟» و دو دکمهٔ «آره 💕» و «نه»
- هر کلیک روی «نه»، دکمهٔ «آره» را بزرگ‌تر می‌کند؛ بعد از چند کلیک «آره» جای آن را می‌گیرد
- انتخاب اجباری تاریخ و ساعت
- انتخاب قهوه، پیتزا، پاستا یا کوبیده
- صفحهٔ تبریک نهایی با افکت جشن
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

> در نسخهٔ اولیه، انتخاب‌ها فقط در مرورگر نگه داشته می‌شوند و به سرور ارسال یا در پایگاه داده ذخیره نمی‌شوند.

## نصب روی سرور Ubuntu / Debian

قبل از نصب:
1. رکورد A دامنهٔ خودتان را به IP عمومی سرور وصل کنید. اگر AAAA دارید، به IPv6 درست سرور اشاره کند.
2. پورت‌های TCP **80** و **443** را در فایروال و پنل سرور باز کنید.
3. سرویس دیگری مانند Nginx/Apache نباید پورت‌های 80 و 443 را اشغال کرده باشد (مگر اینکه آن را از قبل با Caddy هماهنگ کرده باشید).

**فقط یک دستور**؛ عبارت `invite.example.com` را با دامنهٔ واقعی خودتان عوض کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/deltashopsiavash/invite/main/scripts/install.sh | sudo bash -s -- invite.example.com
```

این دستور:
- Git و Caddy را نصب می‌کند
- پروژه را در `/opt/invite` دریافت می‌کند
- دامنه را برای نمایش مستقیم فایل‌های استاتیک پیکربندی می‌کند
- HTTPS و تمدید خودکار گواهی SSL را به Caddy می‌سپارد
- فرمان `invite-update` را ایجاد می‌کند

صدور گواهی SSL به تنظیم درست DNS و دسترسی بیرونی پورت‌های 80/443 وابسته است. اگر دامنه هنوز به سرور وصل نیست، HTTPS ممکن است تا زمان اتصال دامنه فعال نشود.

**نکته:** اگر از قبل سایت‌های دیگری روی همین سرور دارید، اول وضعیت وب‌سرور و پورت‌ها را بررسی کنید. نصب روی سرور تازه توصیه می‌شود.

## آپدیت بعدی؛ بدون بیلد یا ری‌استارت

بعد از اینکه فایل‌های جدید به شاخهٔ `main` در GitHub اضافه شدند:

```bash
sudo invite-update
```

این دستور `git pull --ff-only` اجرا می‌کند. Caddy فایل‌های سایت را مستقیماً از دیسک می‌خواند؛ بنابراین تغییرات با رفرش صفحه دیده می‌شوند. اگر فایل‌های نسخهٔ Git روی سرور دستکاری شده باشند، آپدیت برای محافظت از آنها متوقف می‌شود.

## عیب‌یابی SSL

```bash
sudo systemctl status caddy --no-pager
sudo journalctl -u caddy -n 100 --no-pager
sudo caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile
```

## اجرای سایت روی کامپیوتر

```bash
cd site
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.
