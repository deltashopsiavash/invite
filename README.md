# Invite 💌 — نسخه ۳: لینک اختصاصی برای هر شخص

سایت دعوت عاشقانه، فارسی و موبایل‌محور با قلب/پاکت صورتی متحرک روی بک‌گراند آبی، تقویم شمسی، پنل مدیریت، عکس/ایموجی اختیاری و ذخیره انتخاب‌های طرف مقابل.

## نصب روی سرور تازه (Ubuntu / Debian)

ابتدا رکورد A دامنه را به آی‌پی **همان سرور** وصل کن. اگر رکورد AAAA داری، باید به آی‌پی IPv6 درست وصل باشد. پورت‌های TCP 80 و 443 را باز نگه دار و مطمئن شو وب‌سرور دیگری آنها را اشغال نکرده است.

این دستور را روی **سرور تازه** اجرا کن:

```bash
curl -fsSL https://raw.githubusercontent.com/deltashopsiavash/invite/main/scripts/install.sh | sudo bash
```

نصاب از تو می‌پرسد:
```text
دامنه: somi.deltamarket5.ir
```

**فقط نام دامنه، بدون https://**. روی سروری که ترمینال تعاملی ندارد، می‌توانی دامنه را مستقیم بدهی:

```bash
curl -fsSL https://raw.githubusercontent.com/deltashopsiavash/invite/main/scripts/install.sh | sudo bash -s -- somi.deltamarket5.ir
```

نصاب Git، Node.js، npm و Caddy را نصب می‌کند، برنامه را در `/opt/invite` کپی می‌کند، سرویس `invite-api` و HTTPS خودکار را پیکربندی می‌کند. برای کارکرد SSL، DNS و پورت‌های 80/443 باید درست باشند. نصب روی سروری که سرویس دیگری روی همین پورت‌ها دارد نیازمند بررسی تنظیمات قبلی است.

در انتها **رمز ورود اولیه پنل مدیریت** فقط یک‌بار نمایش داده می‌شود. آن را ذخیره کن.

## پنل مدیریت و لینک‌ها

بعد از نصب به این صفحه برو:

```text
https://YOUR-DOMAIN/admin/
```

در بخش «لینک‌های اختصاصی»، نام شخص را وارد کن. اگر نام انتهای لینک را خالی بگذاری، از اسم او ساخته می‌شود:

- نام «ساغر» → `https://YOUR-DOMAIN/ساغر`
- نام «مریم» با مسیر `maryam` → `https://YOUR-DOMAIN/maryam`

برای نام تکراری بدون تعیین مسیر، پسوند شماره افزوده می‌شود. در پنل هر لینک را انتخاب کن و متن‌ها، نام، عکس/ایموجی را جداگانه ویرایش و ذخیره کن. آدرس همان لینک قابلیت کپی دارد. اگر مسیر لینک را تغییر بدهی، **لینک قبلی از دسترس خارج می‌شود**.

در «جواب‌ها»، می‌توانی همه پاسخ‌ها یا پاسخ‌های یک لینک را ببینی و CSV همان فیلتر را دریافت کنی. حذف لینک، پاسخ‌های ثبت‌شده قبلی را از گزارش «همه لینک‌ها» پاک نمی‌کند.

در نسخه فعلی تنها کسی که رمز پنل را دارد می‌تواند متن‌ها را تغییر دهد یا جواب‌ها را ببیند؛ **خودِ لینک‌های دعوت عمومی‌اند و هرکسی لینک را داشته باشد می‌تواند پاسخ بدهد**.

## ارتقای سروری که قبلاً این سایت نصب شده

اگر پوشه `/opt/invite` **از قبل وجود دارد**:

```bash
sudo invite-update
```

یا برای اولین ارتقا از نسخه قدیمی:
```bash
sudo bash -c 'cd /opt/invite && git pull --ff-only origin main && bash scripts/deploy.sh'
```

این دستورات مخصوص سرور قبلاً نصب‌شده هستند؛ روی سرور تازه از دستور نصب بخش اول استفاده کن.

## دامنه متفاوت روی سرورهای متفاوت

هر سرور نصب، دیتابیس، پنل و دامنه مستقل خودش را دارد. هر مرتبه روی سرور جدید، دستور نصب تازه را اجرا و نام دامنه جدید را وارد کن. نیاز به تغییر کد یا Build نیست.

## آپدیت‌های بعدی

```bash
sudo invite-update
```

تغییرات شاخه main از GitHub دریافت می‌شوند، دیتابیس در `/var/lib/invite` می‌ماند و نسخه پشتیبان محلی ایجاد می‌شود. آپدیت فقط سرویس بک‌اند را ری‌استارت می‌کند؛ نیازی به Docker یا بیلد نیست.

## عیب‌یابی

```bash
sudo systemctl status invite-api caddy --no-pager
sudo journalctl -u invite-api -n 60 --no-pager
curl -i http://127.0.0.1:3477/api/health
sudo journalctl -u caddy -n 60 --no-pager
```

فایل‌های سایت: `/opt/invite/site`  
کد بک‌اند: `/opt/invite/server/index.js`  
دیتابیس: `/var/lib/invite/invite.sqlite`  
عکس‌ها: `/var/lib/invite/uploads`  
بکاپ‌ها: `/var/lib/invite/backups`  
Caddy: `/etc/caddy/sites/invite.caddy`

رمزها با scrypt هش می‌شوند، نشست مدیریت کوکی HttpOnly/Secure/SameSite و CSRF دارد، سرور API فقط روی localhost اجرا می‌شود. از `/var/lib/invite` بکاپ خارج از سرور هم تهیه کن.
