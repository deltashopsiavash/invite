# Invite 💌 — نسخه دوم

سایت عاشقانه چهارمرحله‌ای با بک‌گراند آبی، قلب‌ها و پاکت‌نامه‌های صورتی متحرک، تقویم واقعی **شمسی**، انیمیشن قلب هنگام کلیک، پنل مدیریت رمزدار و ذخیره پاسخ‌ها با SQLite.

## ویژگی‌ها
- کلیک روی «نه» صرفاً «آره» را بزرگ‌تر می‌کند تا جای آن را بگیرد.
- تاریخ با تقویم شمسی نمایش داده می‌شود و برای ذخیره‌سازی، معادل معتبر میلادی هم نگه داشته می‌شود.
- پنل مدیریت: نام مخاطب، متن‌های تمام مراحل، عکس یا ایموجی مستقل هر مرحله، تغییر رمز.
- آپلود فایل‌های JPEG/PNG/WebP/GIF تا ۳ مگابایت.
- مشاهده ۲۰۰ پاسخ آخر در پنل و دریافت CSV تمام پاسخ‌ها.
- صفحه نهایی، تاریخ شمسی، ساعت و غذای انتخاب‌شده را شبیه نمونه مرجع نشان می‌دهد.
- بدون نیاز به Docker یا بیلد دوباره برای تغییرات فرانت؛ در آپدیت، سرویس بک‌اند به‌صورت خودکار راه‌اندازی مجدد می‌شود.
- فایل‌های عکس و دیتابیس بیرون از Git، در /var/lib/invite نگهداری می‌شوند.

## ارتقای سایت نصب‌شده (نسخه یک → دو)
اگر سایت قبلاً در /opt/invite نصب شده، **فقط یک‌بار** این دستور را روی سرور اجرا کنید:

~~~bash
sudo bash -c 'cd /opt/invite && git pull --ff-only origin main && bash scripts/deploy.sh siavash.deltamarket5.ir'
~~~

این دستور به‌صورت خودکار Node.js (نسخه ۱۸ یا بالاتر)، وابستگی‌ها، سرویس systemd و مسیرهای Caddy را راه‌اندازی می‌کند. اگر روی سرور Node کمتر از ۱۸ نصب باشد، نصب متوقف می‌شود و باید آن را ارتقا داد.

**رمز مدیریت اولیه فقط یک‌بار در پایان نصب/ارتقا نمایش داده می‌شود**. آن را ذخیره و بعداً در پنل عوض کنید.

- سایت: https://siavash.deltamarket5.ir/
- پنل: https://siavash.deltamarket5.ir/admin/

## آپدیت‌های بعدی

~~~bash
sudo invite-update
~~~

دستور تغییرات شاخه main را دریافت و در صورت نیاز وابستگی‌های Node را نصب می‌کند، بک‌اند را ری‌استارت و تنظیمات Caddy را بررسی می‌کند. دیتابیس و تصاویر باقی می‌مانند و از دیتابیس هنگام هر آپدیت نسخه پشتیبان گرفته می‌شود.

## نصب تازه روی Ubuntu / Debian

ابتدا رکورد DNS دامنه را به سرور متصل کنید و پورت‌های TCP 80 و 443 را باز بگذارید. مطمئن شوید Nginx/Apache روی همین پورت‌ها با Caddy تداخل نداشته باشد:

~~~bash
curl -fsSL https://raw.githubusercontent.com/deltashopsiavash/invite/main/scripts/install.sh | sudo bash -s -- invite.example.com
~~~

عبارت invite.example.com **نمونه است** و باید با دامنه خودتان جایگزین شود.

## محل‌ها و راهنمای عیب‌یابی
- کد: /opt/invite
- دیتابیس: /var/lib/invite/invite.sqlite
- آپلودها: /var/lib/invite/uploads
- بکاپ‌ها: /var/lib/invite/backups
- سرویس: invite-api
- پورت داخلی: 127.0.0.1:3477
- Caddy: /etc/caddy/sites/invite.caddy

~~~bash
sudo systemctl status invite-api caddy --no-pager
sudo journalctl -u invite-api -n 60 --no-pager
curl -i http://127.0.0.1:3477/api/health
curl -I https://siavash.deltamarket5.ir/
~~~

## امنیت و محدودیت‌ها
رمز با scrypt ذخیره می‌شود؛ نشست مدیریتی کوکی HttpOnly + Secure + SameSite=Strict و CSRF دارد. API فقط روی localhost اجرا می‌شود. آپلودها نام تصادفی دارند، محدودیت حجم و بررسی امضای فایل دارند. نرخ تلاش ورود و ارسال جواب محدود شده است.

این نسخه برای یک سایت شخصی کم‌ترافیک و یک فرآیند Node طراحی شده است. داده‌ها روی همان سرور نگهداری می‌شوند؛ برای بازیابی هنگام از دست رفتن سرور، از /var/lib/invite بکاپ خارج از سرور هم بگیرید.
